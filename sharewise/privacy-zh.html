ALPINNO 出品的 ShareWise

ShareWise 隐私声明

生效日期：2026年11月3日

责任主体与本声明的适用范围

本声明适用于计划推出的 ShareWise Microsoft Store 版本，包括基础应用和两个订阅附加功能。Microsoft Store 认证仍在审核中，本声明不表示应用已在 Store 上架。有关便携版的供应情况和许可，可向 ALPINNO 咨询。

ShareWise 由 ALPINNO GmbH 提供，地址为 Acherhofstrasse 27, 6430 Schwyz, Switzerland。隐私问题和请求可发送至 info@alpinno-solutions.ch，或通过我们的联系表单提交。

您选择处理的文档

ShareWise 访问您选择打开的文档、图像、粘贴的文本、词语列表及还原文件。这些内容可能包含个人信息或机密信息。应用使用这些内容提取文本、对印刷文字进行 OCR、识别并替换所选信息、显示结果供您检查，并在您要求时还原对应的占位符。文档分析和 OCR 使用随附模型在您的电脑上运行。

ShareWise 不会将文档、提取的文本、还原映射或已学习的词语发送给 ALPINNO 或在线 AI 服务进行处理。将导出的结果分享给其他应用或服务是由您控制的独立操作，并受接收方自身的数据处理方式约束。

保存在您电脑上的信息

  • 偏好设置：语言、界面和处理选项、输出文件夹位置以及所选词语列表文件的引用保存在您的 Windows 用户配置文件中。偏好设置不保存源文档副本或导入的词语列表内容。
  • 修正学习：默认启用，仅记住您明确作出的保留或隐藏修正中的准确词语和类别。它不会从未操作的建议项中学习。您可在设置中关闭学习，并另行清除已保存的修正。
  • 已保存的输出：导出的文本和还原映射保留在您保存的位置。初始默认位置是实际 Windows 桌面上的 ShareWise 文件夹；您可以选择其他位置。
  • 本地诊断日志：此功能可选，新安装时默认关闭。日志记录范围有限的技术元数据，例如处理阶段、计数、耗时、资源使用和安全的错误类型，不包含文档内容、私密值、源文件名或路径以及许可内容。ShareWise 不会自动将日志发送给 ALPINNO。日志在达到 1 MiB 大小阈值时轮转，保留当前文件和最多两个备份；没有按时间自动到期删除的机制。
  • 临时处理文件：某些操作会创建本地临时文件。工作进程正常关闭或取消时会清理临时文件。中断或系统故障可能留下残留文件；无法保证安全擦除。

ShareWise 不对导出的文本、还原映射和已学习词语的 CSV 文件加密。还原映射包含原始私密值。请保护您的 Windows 账号、设备和存储空间，并将映射与您分享的文本分开保管。如果桌面或其他所选文件夹与 OneDrive 同步、被备份或共享，这些服务可能根据各自设置复制文件。

将输出复制到剪贴板后，Windows 剪贴板功能和您粘贴内容的应用即可使用它。ShareWise 不控制这些应用或您的 Windows 剪贴板设置。

Microsoft Store 购买与许可

Store 版本使用 Microsoft Store 服务进行购买、订阅和许可检查。这些操作可能需要连接 Microsoft。应用使用 Microsoft 签发的许可状态、订阅标识符和到期信息来确定处理功能的访问权限。缓存的有效许可在其有效期内可能支持离线处理。Store 购买和许可管理可能需要 Microsoft 账号；ShareWise 无需单独的 ALPINNO 账号。

Microsoft 负责 Store 账号、支付信息、计费和取消订阅。ShareWise 不收集您的支付卡信息或 Microsoft 账号密码。Microsoft 服务适用其自身的隐私声明和条款；这些内容不能替代适用于 ShareWise 本身的本声明。

Microsoft 报告与应用诊断

ShareWise 没有 ALPINNO 使用追踪或广告服务。Windows 和 Microsoft Store 可能按照 Microsoft 的设置和条款，单独处理平台诊断及交易信息。ALPINNO 目前不访问或下载 Microsoft 诊断报告。Microsoft 可能向 ALPINNO 提供汇总的获取量和销售统计，这些统计与诊断报告不同。如果收到 Microsoft 应用分析信息，ALPINNO 仅将其用于改进 ShareWise，不用于识别单个用户或设备，也不与第三方数据合并。

如果 ALPINNO 将来收到 Microsoft 错误或诊断报告，仅将其用于调查兼容性、缺陷和质量问题。这些报告可能包含技术和个人信息。个人信息将保密处理，访问权限仅限获授权调查这些问题的人员。个人信息将在收到后 30 天内删除；如果 Microsoft 要求更早删除，则按其要求执行。这些个人信息不会为其他目的而披露。

支持与网站联系

如果您联系 ALPINNO，我们会收到您选择发送的信息，例如联系方式、问题描述或附件。请仅提供必要信息，并在发送前移除机密内容。我们使用这些信息回复并提供支持。支持咨询信息将在合理必要的期限内保留，以便回复、管理由此产生的业务关系，并满足法律或记录保存义务。含有个人或机密信息的不必要附件，在不再需要时会删除。网站、联系处理及隐私请求的说明见ALPINNO 网站隐私声明。

保留期限与您的控制选项

已保存的输出和还原映射会一直保留，直到您删除。偏好设置和已学习的修正保留在您的 Windows 用户配置文件中，直到您更改、清除或删除。卸载应用不能代替删除导出文件或备份、同步文件夹中的副本。

您可在设置中更改输出位置、移除词语列表引用、关闭或清除修正学习，以及开启或关闭本地诊断。关闭学习本身不会删除先前保存的修正；清除是独立操作。关闭诊断不会删除已有日志；您可在本地存储文件夹中删除日志。删除词语列表引用不会删除源文件。

您可以在相应的 Windows 文件夹中访问或删除已保存的输出和映射。许可到期不会删除之前保存的文件。清除修正不会移除先前导出的文件或映射。对于 ALPINNO 通过支持或报告持有的个人信息，请使用上述联系方式联系我们。有关 Microsoft 账号和计费的隐私请求应提交给 Microsoft。

隐私请求与变更

根据适用法律，您可以请求访问、更正、删除 ALPINNO 持有的个人信息或限制其处理，对处理提出异议，或撤回对未来处理的同意。请使用上述联系方式联系我们；可能需要验证身份。有关 Microsoft 账号和计费的隐私请求请提交给 Microsoft。

当 ShareWise 的相关功能或数据处理方式发生变化时，我们会更新本声明。当前声明及其生效或更新日期会在本页公布。
